# Lamerfood 🍓

เว็บแอปถ่ายรูปอาหาร แล้วให้ ChatGPT (OpenAI Vision) บอกชื่อเมนูและแคลอรี่ บันทึกว่าวันนี้กินอะไรไปบ้าง และสรุปแคลอรี่รายวันเทียบกับเป้าหมาย — โทนสีชมพู ใช้ HTML/CSS/JS ล้วน เก็บข้อมูลด้วย localStorage

## ฟีเจอร์
- 📸 ถ่ายรูปหรือเลือกจากคลังรูป → AI วิเคราะห์เมนู ปริมาณ แคลอรี่ โปรตีน/คาร์บ/ไขมัน
- ✏️ แก้ไขชื่อเมนู/แคลอรี่ เลือกมื้อและเวลาได้ก่อนบันทึก
- 🎯 วงแหวนความคืบหน้าเทียบเป้าหมายต่อวัน (ตั้งค่าได้)
- 📊 กราฟ 7 วันล่าสุด และสรุปรายวัน
- ➕ เพิ่มรายการเองโดยไม่ต้องใช้รูป
- 🌙 รองรับโหมดมืด

## วิธีใช้
1. เปิดผ่าน web server (เช่น GitHub Pages หรือ `python3 -m http.server`)
2. ไปที่แท็บ **ตั้งค่า** แล้วใส่ OpenAI API key
3. กดปุ่มกล้องเพื่อถ่ายรูปอาหาร

> API key ถูกเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ควรใช้บนเครื่องสาธารณะ
> แคลอรี่เป็นค่าประมาณจาก AI ใช้เพื่อการติดตามเบื้องต้นเท่านั้น
